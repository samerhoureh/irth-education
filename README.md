# أرث التعليم العربي — Irth Arabic Education

> **لكل طالب عربي معلمُ خصوصيٌّ يدعم مسيرته التعليمية.**

منصة تعليمية عربية شاملة تجمع مناهج **22 دولة عربية** تحت سقف واحد: كتب المواد المعتمدة، ومعلمٌ ذكيٌّ خاص يفهم ثقافة كل طالب ولهجته، وحسابات مجانية للطلاب بفضل برنامج دعم الرعاة.

**تنويه تربوي:** التطبيق لا يعني إلغاء المدرسة أو المعلم الحقيقي، بل هو سندٌ ودعمٌ كمدرسِ خصوصيٍّ لمراجعة دروس الطالب من خلال كتاب المدرسة نفسه.

---

## ✨ المزايا

- 🌍 **مناهج 22 دولة عربية** — السعودية، الإمارات، الكويت، قطر، البحرين، عمان، اليمن، العراق، سوريا، لبنان، الأردن، فلسطين، مصر، السودان، ليبيا، تونس، الجزائر، المغرب، موريتانيا، الصومال، جيبوتي، جزر القمر — بموادّ مطابقة للمناهج الرسمية المعتمدة.
- 🤖 **المعلم الذكي «أرث»** — معلم خصوصي يتقمص ثقافة بلد الطالب ولهجته في الترحيب والتحفيز، ويشرح بالمصطلحات الدراسية المعتمدة في كتب بلده، مع جلسة تعليمية راقية: شرح كامل ← سؤال تحقق ← تشجيع.
- 📸 **فهم بصري وصوتي** — الطالب يرفع صورة صفحة كتابه فيشرحها خطوة بخطوة، ويرسل رسالة صوتية فيتحول كلامها إلى نص ويتفاعل معه المعلم.
- 🔊 **تحويل النص إلى كلام** — ردود المعلم الذكي مسموعة بصوت واضح.
- 📚 **مكتبة الكتب المدرسية** — رفع كتب PDF والتحقق الآلي من أن الصفحة المرفوعة صفحة كتاب حقيقية ذات صلة بالمادة.
- 🛡️ **بوابة موحدة للطلاب والمعلمين** — أدوار: طالب، معلم، مدير، داعم.
- 💛 **برنامج دعم الرعاة** — باقات دعم التعليم العربي (برونزية 200 طالب / فضية 500 طالب / ذهبية 1000 طالب)، ولوحة شرف للداعمين تعرض المساهمة الإنسانية دون أي تفاصيل تجارية.
- 📱 **تطبيق PWA** — يُثبَّت على الهاتف ويعمل كتطبيق مستقل بواجهة عربية RTL كاملة.

## 🧰 التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router) + TypeScript 5 |
| الواجهة | Tailwind CSS 4 + shadcn/ui + framer-motion + lucide-react |
| قاعدة البيانات | Prisma ORM + SQLite |
| الذكاء الاصطناعي | بوابة موحّدة (`src/lib/ai`) — محادثة، رؤية، صوت إلى نص، نص إلى كلام |
| الصوتيات | MediaRecorder API + خدمة ASR/TTS |

## 🚀 التشغيل السريع

```bash
# 1) تثبيت الحزم
bun install        # أو: npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env
#   ثم عدّل: DATABASE_URL وإعدادات بوابة الذكاء الاصطناعي وحسابات الإدارة

# 3) إنشاء قاعدة البيانات
bun run db:push

# 4) بذر البيانات (بالترتيب)
bun run seed:base         # الدول والمراحل والصفوف والمواد الأساسية
bun run seed:curriculum   # مزامنة المواد مع مناهج 22 دولة رسمياً
bun run seed:culture      # تخصيب الهوية الثقافية واللهجية للمعلم الذكي
bun run seed:accounts     # حساب الإدارة والمعلم (من قيم .env)
bun run seed:sponsors     # (اختياري) داعمون تجريبيون

# 5) التشغيل
bun run dev               # ثم افتح http://localhost:3000
```

## 🔌 بوابة الذكاء الاصطناعي

كل خدمات الذكاء الاصطناعي تمر عبر عميل موحّد في `src/lib/ai` يقرأ إعداداته من متغيرات البيئة:

```env
AI_GATEWAY_BASE_URL=https://your-ai-gateway.example.com/v1
AI_GATEWAY_API_KEY=your-key
# AI_GATEWAY_EXTRA_HEADERS={"X-Custom":"value"}   # ترويسات إضافية إن لزم
```

النقاط النهائية المستخدمة: `chat/completions` (نصية وبصرية)، `audio/asr` (كلام إلى نص)، `audio/tts` (نص إلى كلام). استبدل الرابط والمفتاح بأي بوابة متوافقة تملكها.

## 📁 بنية المشروع

```
src/
  app/                # صفحات ومسارات API (App Router)
    api/ai/           # المعلم الذكي: محادثة، صوت، تدقيق الكتب
    api/auth/         # التسجيل والدخول الموحد
    api/sponsors/     # الرعاة والرعايات ولوحة الشرف
    api/admin/        # لوحة الإدارة
  components/platform # مكونات المنصة (الدردشة، البوابة، لوحات الرعاة والإدارة)
  lib/ai              # عميل بوابة الذكاء الاصطناعي الموحّد
  lib/db.ts           # عميل Prisma
prisma/schema.prisma  # مخطط قاعدة البيانات
scripts/              # سكربتات البذر والمزامنة
public/               # الأعلام والأيقونات وملفات PWA
```

## 🔒 الأمان

- كلمات المرور مُلبَّدة بـ scrypt.
- صلاحيات الأدوار مفصولة: طالب / معلم / مدير / داعم.
